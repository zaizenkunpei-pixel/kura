Kura プライバシーポリシー

このポリシーは、Kura（以下「本アプリ」）が Google アカウントと連携したときに受け取る情報の扱いを定めます。

取得する情報

  • Google Tasks のタスク（タイトル、メモ、期日、完了状態）
  • Google アカウントのメールアドレス（どのアカウントと連携しているかを表示するため）

利用目的

利用者本人の Kura の TODO と、本人の Google Tasks を同期するためだけに使います。広告、分析、AI モデルの学習には使いません。

保存場所

  • Google との連携に必要な認証情報は、利用者のパソコン内に Windows の機能（DPAPI）で暗号化して保存します。
  • Google Tasks から取り込んだ内容は Kura のメモとして利用者のパソコンに保存されます。本アプリを利用している組織が同期サーバーを運用している場合は、その組織のサーバーを通じて本人の端末間で同期されます。開発者がこれらの情報を受け取ることはありません。

第三者への提供

取得した情報を第三者に提供・販売することはありません。

連携の解除

Kura の設定「外部連携」の「連携を解除」で、いつでも解除できます。Google アカウントの設定（https://myaccount.google.com/permissions）からも取り消せます。

Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリが Google API から受け取った情報の利用および他のアプリへの転送は、制限付き使用の要件を含め、Google API Services User Data Policy に従います。
